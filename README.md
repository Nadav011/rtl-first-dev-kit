# RTL First Dev Kit

Local scaffold for the RTL-first toolkit planned in Phase 3.

## Status

This is a draft structure only. It does not claim the toolkit is complete, published, or battle-tested.

## Layout

- `tailwind/` - logical-direction mapping notes and examples
- `flutter/` - directional Flutter patterns
- `nextjs/` - App Router and `dir` propagation notes
- `biome/` - RTL linting ideas and policy notes
- `ci/` - validation workflow sketches
